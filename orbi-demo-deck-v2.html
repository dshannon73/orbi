Appendix
— Build Story
Built by an SE. Directed to Claude Code.
No engineering background required.
Real Challenges We Hit
Authentication across 5 systems — SF CLI, Google OAuth, Slack MCP, aisuite proxy, org62 sessions. Each had a different auth model.
MCP isn't directly callable from Node — aisuite's Slack proxy runs on a dynamic port with a session-only secret. Required spawning Claude as a subprocess to use MCP tools.
Claude's safety filters block tool-call style prompts — natural language + neutral working directory was the fix.
React state mismatch — mixing localStorage, Zustand, and local useState for the same value caused "button does nothing" bugs.
What I'd Do Differently
Learn CLAUDE.md and memory files first. Found them at AI Day after most of Orbi was built.
Design the data model on paper first. Calendar → attendees → accounts → opps → DCs. Explaining it incrementally caused drift.
Test in the actual app. Claude reports "clean compile" confidently. Real bugs only show at runtime.
Pick one state layer. Mixing state mechanisms for the same value always causes pain.
